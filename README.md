# OCB Omni — Chọn tất cả giao dịch

Chrome extension thêm nút **"Chọn tất cả"** vào bảng *Sao kê tài khoản* trên
[OCB Omni KHDN](https://omnicorp.ocb.com.vn/) để tick hàng loạt giao dịch
chỉ với 1 click, rồi tải UNC / Giấy báo Nợ / Giấy báo Có theo lô qua nút
**"TẢI VỀ CHI TIẾT"** sẵn có của OCB.

Trên màn *Hóa đơn điện tử*, extension thêm nút **"Tải tất cả XML / PDF / XML + PDF"**:
tải toàn bộ hóa đơn trong khoảng ngày đang chọn thành 1 file ZIP, kèm `danh-sach.csv`.
